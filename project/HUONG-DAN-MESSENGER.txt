MUC 2: APP SECRET (ma bi mat cua App)
----------------------------------------------------------------
App Secret dung de kiem tra chu ky moi tin nhan Facebook gui toi
(chong gia mao). KHONG chia se cho ai, KHONG dang len mang.

Cac buoc lay:
  1. Vao developers.facebook.com -> My Apps -> chon App cua ban.
  2. Menu trai: App Settings -> Basic.
  3. O App Secret: bam Show -> nhap mat khau Facebook -> copy ma.
  4. Mo file .env bang Notepad, tim dong:
       MESSENGER_APP_SECRET=
     dan ma vao sau dau =, vd:
       MESSENGER_APP_SECRET=abc123def456...
  5. Luu file .env. Khoi dong lai Server de nhan (tat mo lai
     file 2-Khoi-Dong-Server.bat).
  6. Tu test: gui POST khong chu ky vao link webhook phai bi 401.
     (Toi da test san: sai/khong chu ky -> 401, dung -> qua.)

MUC 3: PAGE ID + PAGE ACCESS TOKEN (quyen nhan tin thay Page)
----------------------------------------------------------------
Page ID cho bot biet nhan tin bang Page nao. Page Access Token la
"chia khoa" de bot duoc phep gui tin nhan di. Token nay mat la
phai tao lai, giu kin nhu mat khau.

Cac buoc lay:
  1. Trong App Dashboard -> phan Messenger (Use Case) -> muc
     Access Tokens (hoac: Messenger -> Settings).
  2. Bam Add hoac chon Fanpage cua ban trong danh sach.
     Facebook se hoi cap quyen: chap nhan day du (pages_messaging,
     pages_manage_metadata...). Ban phai la Admin cua Page.
  3. Bam Generate Token -> copy chuoi dai bat dau bang EAA... 
  4. Lay Page ID: vao Fanpage -> Gioi thieu (About), keo xuong
     thay Page ID (day so). Hoac trong Business Suite -> Cai dat.
  5. Mo file .env, dien 2 dong:
       MESSENGER_PAGE_ACCESS_TOKEN=EAA...
       MESSENGER_PAGE_ID=day-so-page-id
  6. Luu file .env. Khoi dong lai Server.
  7. Luu y: nick dang nhap Facebook de lay token phai GIU quyen
     Admin Page. Mat quyen la token chet theo, phai tao lai.
